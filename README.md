# Учи — сайт-помощник школьника (готовый шаблон)

Один файл `index.html`: без сборки, без серверной части, без регистрации. Открывается двойным кликом или заливается на любой хостинг.

## Что внутри
- Справочник формул (около 135): математика, физика, химия, информатика, биология, география, русский язык. Поиск, фильтр по предметам, избранное.
- Тренажёр с экранной цифровой панелью, зубрилка (карточки), планер домашки, таймер фокуса.
- Группы и чат, профиль с аватаром и достижениями, уровни, XP, серия дней, цель на день, отсчёт до экзамена, блокнот.
- Настройки: тема, 10 фонов, акцентный цвет, размер текста, экспорт/импорт данных, сброс.
- Данные сохраняются в браузере (localStorage, ключ `uchi:v1`), в том числе при закрытии вкладки.
- Страница «О проекте» с политикой конфиденциальности и условиями (шаблонные тексты).

## Запуск за 5 минут
1. Открой `index.html` в браузере, чтобы проверить.
2. Размести: Netlify Drop (перетащи файл), GitHub Pages, Cloudflare Pages или любой хостинг.

## Свой бренд
В начале скрипта найди строку `const BRAND={...}` и поменяй `name`, `mail`, `year`. Название, заголовок вкладки, футер и страница «О проекте» обновятся сами. Для смены цветов правь переменные `--acc`, `--bg` в начале `<style>`.

## Общий чат между устройствами
Без настройки чат работает только на устройстве пользователя. Чтобы сообщения видели все участники группы:
1. Создай проект в Firebase, включи Realtime Database.
2. Скопируй адрес базы вида `https://имя-default-rtdb.firebaseio.com`.
3. Вставь его в `BRAND.fbUrl` в `index.html`.

Важно: интеграция написана по описанию REST API Firebase и на реальной базе при подготовке не проверялась, проверь после подключения. Правила базы нужно настроить самому (по умолчанию в тестовом режиме база открыта всем), модерации в чате нет. Для публичного запуска с детьми нужны авторизация и модерация на серверной части.

## Как добавить формулы
В массиве `F` каждая строка имеет вид `Предмет|Тема|Название|Формула|Пояснение`. Новые предметы появляются в фильтрах автоматически.

## Ограничения
Нет аккаунтов и серверной части, данные привязаны к браузеру, чат без модерации, формулы справочные (сверяй с учебником). Код создан с помощью ИИ и доработан по описанию заказчика.
